# MyNav 🧭

MyNav 是一个极简、专注于键盘操作效率的个人导航页。

这个项目的核心场景非常明确：**配合 [Vimium C](https://github.com/gdh1995/vimium-c)（或其他类似扩展）使用，实现纯键盘的极速网页导航。** 同时，它结合了前端 AES 强加密，让你可以安心地将私密书签托管在 GitHub Pages 等公开服务上，而不用担心隐私泄露。

## ✨ 特性

- ⌨️ **Vimium C 绝佳伴侣**：所有链接均采用大按钮设计，间距舒适。按下 `f` 键，Vimium C 能够精准生成易读的字母标签，盲打直达目标网站，完全抛弃鼠标。
- 🔐 **前端端到端加密**：使用 `crypto-js` 对核心数据进行 AES 加密。在公开仓库（如 GitHub Pages）中只存储加密后的 `.enc` 文件，哪怕仓库开源，没有密码也绝对安全。
- 👁️ **公开/私密双模式**：
  - 默认加载 `demo.json`，展示常规或可以公开的网站。
  - 点击“加载私密链接 🔐”，输入密码后，页面会瞬间解密并渲染你的私人书签。
- 📊 **本地点击统计**：每次点击书签都会被本地记录。你可以随时点击右下角的“导出并清理记录”来下载 `.txt` 格式的访问日志。
- ⚡ **无后端纯静态**：部署毫无压力，随处可挂，只要有个能访问静态文件的地方就能跑。

## 🚀 快速开始

### 1. 本地环境准备

克隆项目到本地后，安装加密脚本所需的依赖：

```bash
# 初始化并安装依赖 (如果你还没有的话)
npm install
```

### 2. 配置你的导航数据

修改 `links3.json`（如果不存在请新建），参照 `link_schema.json` 规范编写你的书签列表：

```json
{
  "搜索引擎": [
    { "text": "Google", "url": "https://www.google.com", "color": "#4285F4" }
  ],
  "常用工具": [
    { "text": "GitHub", "url": "https://github.com", "color": "#333333" }
  ]
}
```

### 3. 加密数据

在终端运行以下命令，将明文的 `links3.json` 加密成前端需要的 `links.enc`：

```bash
node encrypt.js
```

根据提示输入你的密码。请牢记这个密码，这是你在网页端解密查看私密链接的唯一凭证。

> ⚠️ **注意**：`.gitignore` 中已经忽略了 `links3.json`，请确保不要手动把含有私密数据的明文 JSON 推送到公开仓库中！

### 4. 部署

由于这是一个纯前端项目，你只需要将项目推送到你的 GitHub 仓库，并开启 **GitHub Pages** 即可使用。

## 🛠️ Vimium C 配合建议

- 将部署好的网页设为浏览器的 **主页** 或 **新标签页**。
- 按下 `f`，即可呼出字母快捷键，配合肌肉记忆可以做到打开新标签页后一秒内直达常用网站。
- 对于高频使用的公开网站，建议写入 `demo.json` 避免每次输入密码；对于内部项目和个人隐私书签，写入 `links3.json` 加密使用。
