# MyNav icon

Generated using the built-in image generation tool. `mynav-icon.png` is the original; the 16px, 32px, and 180px PNGs are resized exports for the favicon and Apple touch icon. The homepage uses relative asset paths to support GitHub Pages project URLs.

## Generation prompt

Use case: logo-brand. Asset type: square browser favicon for MyNav, a minimal keyboard-oriented personal navigation site whose README uses a compass symbol and whose UI is charcoal with blue accents. Generate one finished flat icon: a bold white and bright blue compass/navigation arrow pointing northeast on a solid charcoal square background, with a simple thick blue compass ring. Extremely simple silhouette, generous stroke widths, centered large mark occupying about 80% of canvas, legible at 16x16 pixels. Square 1024x1024 bitmap. No text, letters, tiny tick marks, shadows, mockup, border padding, or watermark.
